# BESOQ

**Be So Quiet.**

A clothing brand built on the philosophy of quiet confidence. No logos shouting. No noise. Just well-made garments that speak through cut, cloth, and proportion.

This repository hosts the complete brand identity system for BESOQ — strategy, verbal identity, visual identity, applications, and a full design-token library ready for use in product, packaging, and digital surfaces.

---

## Repository structure

```
brand/
├── 00-overview/         Brand at a glance, principles, decision log
├── 01-strategy/         Manifesto, positioning, audience, architecture
├── 02-verbal/           Naming, voice, tagline system, messaging, copy
├── 03-visual/           Logo, color, typography, grid, photography, motion
├── 04-applications/     Packaging, labels, stationery, retail, digital
├── 05-product/          Collection naming, SKU, materials, sizing, care
├── 06-guidelines/       Do & don't, accessibility, legal, checklist
├── 07-tokens/           CSS variables, JSON tokens, Tailwind preset
├── assets/              SVG wordmarks, monograms, seals, patterns
└── CHANGELOG.md
```

## How to use this system

1. **Start at `brand/00-overview/README.md`** for the brand at a glance.
2. **Strategists & founders** → read `01-strategy/`.
3. **Copywriters & marketers** → read `02-verbal/`.
4. **Designers** → read `03-visual/` and `06-guidelines/`.
5. **Engineers** → consume tokens from `07-tokens/` and assets from `assets/`.

## Versioning

This is brand system **v1.0** — the founding canon. Material additions or revisions are tracked in `brand/CHANGELOG.md` and require a pull request with sign-off from the brand owner.
