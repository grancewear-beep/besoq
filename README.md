# BESOQ

**be so quiet.**

Azərbaycanda istehsal olunan, 22–32 yaş üçün geyim brendi. T-shirt, hoodie, jogger. Sifariş gələndən 24 saat ərzində hazırlanır.

Bu repo brendin bütün sənədlərini saxlayır — strategiya, dil, vizual, qiymət, sayt, instagram, hər şey.

## Bura nə daxildir

```
brand/
├── 00-brif/              brendin əsas məntiqi
├── 01-mövqe/             biz kimik, kimə satırıq, niyə alırlar
├── 02-dil/               necə danışırıq — sayt, instagram, müştəri
├── 03-vizual/            logo, rəng, şrift, foto
├── 04-print/             print kataloqu və qaydalar
├── 05-məhsul/            daimi xətt, drop-lar, ölçülər
├── 06-əməliyyat/         istehsal, çatdırılma, qiymət, ödəniş
├── 07-instagram/         post planı, kontent qaydaları
├── 08-tokens/            kod üçün rəng və şrift dəyərləri
└── assets/               logo və ikon faylları
```

## Haradan başlamalı

İlk dəfə oxuyursansa, sıra ilə:

1. `brand/00-brif/oxu-bunu-əvvəl.md`
2. `brand/01-mövqe/biz-kimik.md`
3. `brand/02-dil/necə-danışırıq.md`

İcraçısansa (sayt qurursan, foto çəkirsən, post yazırsan), birbaşa öz bölməni aç.

## Versiya

Bu **v2** — sənin print-on-demand modelinə uyğun, orta seqmentdə, Azərbaycan bazarı üçün. Köhnə lüks versiya `brand/identity` branch-ında qaldı, məsləhət üçün.
