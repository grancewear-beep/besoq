# Do & don't

The single most-referenced page in the brand kit. Every "do" is a small action; every "don't" is a small drift caught early. The list is opinionated, alphabetised by category, and updated by PR when a new pattern emerges.

For the more granular checklist used before each surface ships, see `04-brand-checklist.md`.

---

## Strategy

| ✅ Do | ❌ Don't |
|---|---|
| Trace every decision to a pillar. | Make a decision because "it tested well." |
| Cut a piece that doesn't earn its place. | Add another piece because the calendar says so. |
| Release when the cloth is right. | Release because a competitor just released. |
| Treat the customer like an adult. | Treat the customer as a target, traffic, or eyeballs. |
| Refuse to participate in industry rituals (Black Friday, drops, capsules). | Find a "BESOQ-appropriate" way to participate. |
| Make slowness a feature. | Apologise for being slow. |
| Refuse a collaboration that would dilute the brand. | Take a collaboration because the partner is bigger than us. |

## Voice & copy

| ✅ Do | ❌ Don't |
|---|---|
| Lowercase, throughout. | Title-case headlines or sentence-case marketing. |
| Em dashes with a single space on each side. | Hyphens, en dashes, or no spaces. |
| Periods on standalone lines. | Lines that float without punctuation. |
| Speak in cloth, weight, and mill. | Speak in vibes ("luxurious," "premium"). |
| Use the customer's first name in service emails. | Use the customer's first name in marketing emails. |
| End emails with `— besoq` (or a person's name). | Sign off with "Cheers!" or "Stay quiet ✨". |
| Cut adjectives ruthlessly. | Add adjectives to "make it pop." |
| Read a sentence aloud before publishing. | Optimise copy for SEO at the expense of voice. |
| Curly quotes (`'…'`, `"…"`). | Straight typewriter quotes (`'…'`, `"…"`). |

## Naming

| ✅ Do | ❌ Don't |
|---|---|
| `besoq — autumn 26` | `BESOQ AW26` / `Besoq Fall 2026` |
| `besoq × [partner]` | `Besoq x Partner` / `BESOQxPartner` |
| `the long coat` | `BESOQ Long Coat` |
| `study no. 03` | `Study #3` / `Study 03` |
| Use the master domain `besoq.com` everywhere. | Buy `besoq.shop` or `getbesoq.com`. |
| `@besoq` on every platform. | `@besoq.official`, `@thebesoq`, `@besoq_az`. |

## Wordmark

| ✅ Do | ❌ Don't |
|---|---|
| Lowercase wordmark, default. | Title-case "Besoq" — never. |
| Letter-space at 0.12em (lowercase) / 0.20em (uppercase). | Tight or default kerning. |
| Use the editorial uppercase only for press, legal, signage. | Use uppercase wherever it "looks bolder." |
| Maintain 2x clear space (twice the e-height). | Crop tight to make the wordmark "fit." |
| Wordmark in Ash on Bone (or Bone on Ash). | Wordmark in red, gold, gradient, or stroked. |
| Use the SVG asset, not a screenshot. | Recreate the wordmark by typing it in any font. |
| Switch to the monogram when below the minimum size. | Squint a too-small wordmark and ship it. |

## Colour

| ✅ Do | ❌ Don't |
|---|---|
| Bone for whites, always. | `#FFFFFF` ever. |
| Ash or Ink for blacks. | `#000000` ever. |
| 2–3 colours per surface. | 4+ colours; "use the whole palette." |
| Use functional state colours for UI errors. | Use bright primary colours for emphasis. |
| Tonal pairings (bone-on-bone). | High-contrast accent stripes. |
| Pair colour with shape or text for state. | Communicate state through colour alone. |
| Add a new accent only with documentation. | Add a new colour for a single campaign. |

## Type

| ✅ Do | ❌ Don't |
|---|---|
| Söhne for sans, Times Now for serif, Söhne Mono for technical. | Add a third typeface "for variety." |
| Inter / Source Serif 4 / JetBrains Mono as fallbacks. | Comic Sans, novelty faces, display faces. |
| Use the modular scale tokens. | Hand-pick `19px` because it "looks right." |
| Use weight 400 (regular) for body. | Use weight 300 (light) for body. |
| Reserve weight 600 for small UI labels. | Bold body text "for emphasis." |
| Tabular figures in prices and tables. | Proportional figures in tables. |
| Curly quotes, em dashes, single ellipsis character. | Straight quotes, hyphens, three dots `...`. |

## Layout

| ✅ Do | ❌ Don't |
|---|---|
| Square corners. | Rounded corners. |
| Designed white space — air targets met. | Filled-up canvases. |
| One hero element per fold. | Three competing CTAs above the fold. |
| Static layouts. | Carousels, parallax, scroll-jacking. |
| Single column for editorial reading. | Multi-column with auto-flow. |
| Paragraph spacing via `1em` gap. | Paragraph indent. |
| Limit page to one `<h1>`. | Multiple `<h1>` tags. |

## Photography

| ✅ Do | ❌ Don't |
|---|---|
| One of the four sanctioned modes (studio garment / on-body neutral / architectural / material study). | Lifestyle narratives with golden-hour light. |
| Subject left or right of frame. | Centre composition with model staring at camera. |
| Soft single source, 4500–5500K. | Hard flash, ring light, mixed temperatures. |
| 4:5 portrait for product. | Square or landscape for product. |
| Disclose model height + size worn. | Hide model details. |
| Cut a photo that looks like a competitor's. | Approve a photo because "it'll do." |
| Use the brand's grading LUT. | Apply Instagram filters. |

## Iconography & graphic elements

| ✅ Do | ❌ Don't |
|---|---|
| Use the 12-icon system. | Add a 13th icon. |
| Stroke-only icons, 1.5u, square caps. | Filled icons or rounded caps. |
| `currentColor` for icon stroke. | Hard-code icon colour. |
| Standard ISO 3758 care symbols. | Custom-illustrated care symbols. |
| Technical line drawings for garment specs. | Hand-drawn or watercolour illustrations. |

---

## Motion

| ✅ Do | ❌ Don't |
|---|---|
| ≤ 240ms transitions. | "Smooth" 600ms hero animations. |
| Single-property motion (opacity OR transform). | Multi-property bounces. |
| Honour `prefers-reduced-motion`. | Force animations on. |
| Page fade between routes. | Page slide / push transitions. |
| Skeleton-loading placeholders. | Spinning logo loaders. |
| Static hero. | Auto-playing hero video with sound. |

## Product

| ✅ Do | ❌ Don't |
|---|---|
| Disclose mill, weight, country of make. | Use vague "premium fabric" language. |
| Restock the permanent line. | Redesign the permanent line each season. |
| Sell archive at original price. | Discount end-of-season. |
| Repair indefinitely. | Limit repair to "first owner only." |
| Price without `.99` endings. | Price at `€ 239,99`. |
| Currency symbol with non-breaking space. | `$240` smashed together. |
| Two collections + permanent + studies. | Pre-fall, resort, holiday capsules. |

## Channel

### Email
| ✅ | ❌ |
|---|---|
| ≤ 18 emails per customer per year. | Daily newsletter, "we miss you" emails. |
| Plain-text-first, single column. | Image-only emails. |
| Single-click unsubscribe. | "Are you sure?" unsubscribe interstitials. |
| Subject ≤ 6 words. | Clickbait subjects with emoji. |

### Social
| ✅ | ❌ |
|---|---|
| Instagram, Pinterest, Are.na, occasional YouTube. | TikTok, Twitter/X, Threads. |
| Zero hashtags. | Trend hashtags. |
| 2–4 IG posts per week, max. | Daily content factory. |
| Single-image posts, 4:5. | Carousels and Reels-by-default. |
| Skip a week if nothing is worth posting. | Apologise for being quiet. |

### Web
| ✅ | ❌ |
|---|---|
| Self-hosted privacy-respecting analytics. | Google Analytics, Facebook Pixel. |
| Performance budget ≤ 600KB homepage. | Heavy JavaScript landing pages. |
| Single-page checkout. | Multi-step funnel with upsells. |
| No coupon field. | Coupon-promo banner above the fold. |

### Retail
| ✅ | ❌ |
|---|---|
| 75% empty space. | Dense merchandising. |
| Single window garment, or empty window. | Multi-mannequin window with vinyl. |
| Silence (or sub-conversation library music). | Spotify playlist branded with the store. |
| Unscented. | Signature diffuser scent. |
| Greet "welcome." | "Hi! Have you been here before?" |

## Customer relationship

| ✅ Do | ❌ Don't |
|---|---|
| Reply to care@besoq.com within 24–48h, by name. | Use a chatbot. |
| Offer a 15-min sizing call. | Push the customer to "complete the look." |
| Repair indefinitely, free shipping both ways. | Charge a "service fee." |
| Acknowledge mistakes publicly. | Quietly delete a poor product. |
| Honour returns without interrogation. | "Tell us why" with 12 mandatory fields. |
| Send a single, well-handwritten compliments slip. | Auto-generate a "personal" thank-you. |

## Marketing & growth

| ✅ Do | ❌ Don't |
|---|---|
| Grow through word of mouth and editorial. | Performance ads at scale. |
| Gift only with no expectation. | Gift "in exchange for a post." |
| Press relationships, named editor by name. | Mass-blast press releases. |
| Treat slow growth as a brand asset. | Hire a growth lead before a brand lead. |
| Refuse the affiliate programme. | Onboard 200 micro-influencers with codes. |
| Allow customers to find us. | Optimise to chase them down. |

## Legal & ethical

| ✅ Do | ❌ Don't |
|---|---|
| Disclose what we know about a cloth. | Claim "luxurious" without backing. |
| Use only "sustainable" claims we can defend. | Greenwash. |
| Honour reduced-motion, dark mode opt-in. | Force aesthetic over user need. |
| Publish what we got wrong. | Quietly delete a problematic post. |
| Pay our makers on time, every time. | Press makers on terms to "save margin." |

## When in doubt — the four governing questions

1. **Is this quiet?**
2. **Is this considered?**
3. **Will this last?**
4. **Is this honest?**

If the answer to all four is yes, ship.
If the answer to any one is no, return to the work.

That is the brand.
