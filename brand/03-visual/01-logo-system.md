# Logo system

BESOQ uses a strict, wordmark-led identity. There is no standalone icon, no graphic mascot, no abstract pictogram. The wordmark is the brand. Everything else is a controlled extension of it.

---

## The system at a glance

| Asset | Form | Use |
|---|---|---|
| **Primary wordmark** | `besoq` (lowercase) | Default. 90% of all uses. |
| **Editorial wordmark** | `BESOQ` (uppercase, tracked) | Press, retail signage, photography credits. |
| **Monogram** | `bsq` (lowercase) | Hardware, embossing, small applications below 8mm. |
| **Seal** | A circle containing `besoq` | Stamps, sealing wax, certificates of repair. |
| **Quiet mark** | A single low dot · | Used at the end of editorial blocks; not a logo per se but a system signature. |

The system is intentionally narrow. Every variant exists for a specific reason. There are no "fun" variants. There are no holiday variants. There are no campaign-customised variants.

---

## 1. Primary wordmark — `besoq`

**Casing.** Lowercase. Always.
**Type.** Set in **Söhne Buch** (or the open-source fallback **Inter Regular**) at a defined letterspacing.
**Letterspacing.** `+120 units` (0.12em on web) — generous, never tight.
**Weight.** Regular (400). Never bold. Never light.
**Aspect.** Set on a single baseline. Never on a curve. Never as a wave.

### Construction grid

```
┌───┬───┬───┬───┬───┐
│ b │ e │ s │ o │ q │
└───┴───┴───┴───┴───┘
   ←x→ ←x→ ←x→ ←x→
```
- `x` is the brand's base unit, equal to the height of the lowercase `e` ("x-height").
- Inter-letter spacing is always proportional to `x`, not to the cap height.
- The wordmark's total width is approximately 8.4x at the standard letterspacing.

### Minimum sizes

| Surface | Minimum size |
|---|---|
| Print | 6mm (full wordmark) |
| Web | 48px wide |
| Embroidery | 12mm wide; below this, switch to monogram |
| Embossing on leather | 8mm wide; below this, switch to monogram |
| Favicon | n/a — use the monogram |

### Clear space

Clear space around the wordmark is `2x` on all four sides — twice the height of the `e`. No element (image, type, edge, or other graphic) may enter this zone.

```
            ←──── 2x ────→
           ┌─────────────────┐
   ↑       │                 │
   2x      │                 │
   ↓       │     besoq       │
           │                 │
   ↑       │                 │
   2x      │                 │
   ↓       └─────────────────┘
            ←──── 2x ────→
```

## 2. Editorial wordmark — `BESOQ`

Used **only** in the contexts named in `02-verbal/01-naming.md`: press releases, legal documents, retail signage, photography credits.

**Casing.** Uppercase.
**Letterspacing.** `+200 units` (0.2em on web) — wider than the lowercase, to compensate for the visual density of caps.
**Weight.** Regular (400). The same weight as the primary wordmark.
**Use density.** Once per surface, at most.

The editorial wordmark exists so that, when uppercase is unavoidable (e.g., a press release headline, a glass storefront sign), the brand has a controlled, credible variant — not an ad-hoc capitalisation of the primary.

---

## 3. Monogram — `bsq`

A three-letter compression of the wordmark, used only when the full mark cannot be applied (size, hardware, embossing).

**Form.** `bsq`, lowercase, set in the same type and letterspacing as the primary wordmark.
**Use cases.**
- Hardware: zipper pulls, button backs, eyelets.
- Embossing on leather goods (wallets, card holders).
- Tonal jacquard on linings (`bsq` repeated as a quiet pattern).
- Favicons and app icons (square crop, see assets).

**Forbidden uses.**
- ❌ Front-of-garment placement.
- ❌ Embroidery on outerwear sleeves or chest.
- ❌ Stitched into seams visibly.
- ❌ Used as a hashtag (e.g., #bsq).

The monogram is a **utility mark**, not a status mark.

---

## 4. Seal

A circular containment of the wordmark, set on a fine border. Used for:
- Wax seals on archive correspondence.
- Stamp impressions on care cards.
- "Repaired by besoq" certificates.
- The inside of presentation boxes.

**Construction.**
- Outer ring: 0.5pt stroke.
- Inner content: `besoq` wordmark, sized to occupy 60% of inner diameter.
- Clear space inside the ring: equal to `1x`.

**Typical sizes.** 22mm (wax seal), 30mm (stamp), 60mm (box interior).

The seal must **never** be used as a logo replacement on a garment label, packaging, or website. It is reserved for ceremonial / service surfaces.

---

## 5. The quiet mark — `·`

A single low dot, set in the body text size, used as an end-mark or a system signature. It is not a logo — it is a typographic period of the brand. Where most brands sign off with a logo, BESOQ sometimes signs off with this dot.

Use sparingly: at the end of an editorial paragraph, at the foot of a long-form page, on the back inside of a hangtag.

## Logo behaviour

### Lockup with line names

When the wordmark must appear with a line name (e.g., on a lookbook cover), the lockup follows the em-dash naming convention from `01-strategy/07-brand-architecture.md`:

```
besoq — autumn 26
```

- The em dash is set with a single space on each side.
- The wordmark and line name share the same type, weight, and size.
- The line name is also lowercase.

### Lockup with collaborator

```
besoq × [partner]
```

- Both names sit at the same size and weight.
- The multiplication sign `×` (not letter `x`, not asterisk `*`) is set with a hair space on each side.
- No merged logos. Ever.

### Lockup with location (retail)

When the wordmark appears on retail signage, it is allowed to sit alongside a city name:

```
BESOQ — BAKU
BESOQ — MILAN
```

In this context only, the editorial uppercase is used, with a tracked dash. Always tracked at +200 units.

## Colour applications

### On light backgrounds
Wordmark in **Ash Black** (`#1A1A1A`).

### On dark backgrounds
Wordmark in **Bone White** (`#F4EFE6`).

### On photography
Wordmark in white, only when contrast against the image is sufficient (WCAG AA at minimum). Never on a busy or coloured background.

### Tonal applications
- Embossed (no colour, only shadow).
- Foil — only **matte** white or **matte** black foil. Never gloss. Never metallic.

### Forbidden colour applications
- ❌ Wordmark in any colour other than the five primary palette colours.
- ❌ Wordmark in gradient.
- ❌ Wordmark with a stroke / outline.
- ❌ Wordmark with a drop shadow (web or print).

---

## Logo misuse — the unacceptable list

The following are explicit violations:

- ❌ Stretching, condensing, or skewing the wordmark.
- ❌ Setting the wordmark in any other typeface.
- ❌ Bolding, italicising, or underlining the wordmark.
- ❌ Adding a tagline directly under the wordmark as a permanent lockup.
- ❌ Placing the wordmark inside a shape (square, circle, badge) — except the defined seal.
- ❌ Using the wordmark as a watermark across an image.
- ❌ Tiling the wordmark into a pattern (use the monogram tonal jacquard instead).
- ❌ Using the wordmark as a button on a website (use a text link instead).
- ❌ Animating the wordmark (no fade-in, no type-on, no shimmer).
- ❌ Reproducing the wordmark in 3D, with depth, or with extrusion.
