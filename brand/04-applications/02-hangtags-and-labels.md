# Hangtags & garment labels

The hangtag is the brand's most-handled printed object. It is touched, held, read, and almost always discarded — which is precisely why it must be made well. A poor hangtag is a small, daily betrayal of the brand.

---

## 1. Hangtag — the standard

The standard hangtag accompanies every garment.

### Specifications
| Spec | Value |
|---|---|
| **Material** | GF Smith Colorplan — Bone, 350 gsm |
| **Size** | 60 × 90mm (portrait) |
| **Print method** | Letterpress, single-colour ash ink |
| **Eyelet** | None — the hangtag is hole-punched (3mm, top centre, 8mm from the edge) |
| **String** | Undyed cotton thread, 1mm twist, natural colour. No plastic, no string tag, no metal seal. |

### Front face

```
┌──────────────────────────────┐
│             ○                │   ← hole, 8mm from top
│                              │
│                              │
│           besoq              │   ← wordmark, 24mm wide
│                              │
│                              │
│            size              │   ← label "size" 9pt
│             m                │   ← size value 18pt
│                              │
│                              │
│                              │
│                              │
└──────────────────────────────┘
```

- Wordmark vertically centred at upper third.
- "size" + value vertically centred at lower third.
- All other space is intentional white.

### Back face

```
┌──────────────────────────────┐
│             ○                │
│                              │
│                              │
│                              │
│                              │
│                              │
│        be so quiet.          │   ← centred, 8pt
│                              │
│                              │
│                              │
│           — besoq            │   ← centred, 7pt
│                              │
└──────────────────────────────┘
```

The back is calmer than the front. Two lines. Lots of paper.

### Inside (folded variant — optional)

For premium garments (coats, jackets) the hangtag is folded — opening to reveal a third surface inside.

```
┌──────────────────────────────┐
│  cloth                       │
│  380 gsm wool, 100%          │
│                              │
│  mill                        │
│  [mill name], biella         │
│                              │
│  make                        │
│  portugal                    │
│                              │
│  care                        │
│  dry-clean only              │
│  store on a wide hanger      │
│                              │
└──────────────────────────────┘
```

Information only. No marketing. No QR code.

## 2. Outer woven label (visible)

The label that appears at the centre-back of the neck, visible on the outside-inside of the garment when looking down the collar.

### Specifications
| Spec | Value |
|---|---|
| **Construction** | Damask-woven cotton tape, soft hand |
| **Size** | 30 × 12mm (W × H) |
| **Tape colour** | Bone (or ash for dark garments) |
| **Type colour** | Ash on bone tape (or bone on ash tape) |
| **Type face** | Söhne Buch — woven to match |
| **Content** | Wordmark `besoq` only. No size, no composition. |

### Placement
- **Tops & jackets**: centre-back, 4mm below the collar seam.
- **Trousers**: centre-back of the waistband, inside.
- **Knitwear**: hand-stitched at centre-back, 6mm below neckline.

### Forbidden
- ❌ Embroidered labels (over-loud).
- ❌ Heat-pressed labels.
- ❌ Labels visible from the outside.
- ❌ Labels on the chest, sleeve, or any external position.

## 3. Inner composition label (printed)

The label that carries information — composition, country of make, size, care symbols, tagline.

### Specifications
| Spec | Value |
|---|---|
| **Construction** | Smooth poly-cotton blend tape, soft hand |
| **Size** | 25 × 80mm (W × H), folded once at midpoint |
| **Tape colour** | Bone |
| **Type colour** | Ash, single-colour print |
| **Type face** | Söhne Buch / Söhne Mono (specs in mono) |
| **Placement** | Side seam, left side of garment, 12mm below pocket entry (or seam reference for that garment type) |

### Content (top to bottom, on one side)

```
besoq

100% cotton

made in portugal

size m
```

### Content (other side, after fold)

```
[care symbols — ISO 3758]

wash cold
line dry
press while damp

be so quiet.
```

The tagline appears on the **inner-most** position — only visible when the customer cuts the label out, or studies it in detail. This is intentional. The tagline is a private discovery, not a public statement.

## 4. Size label (separate, on size-relevant garments)

Some garments — specifically denim, knitwear, and tailoring — carry a separate small size flag.

### Specifications
| Spec | Value |
|---|---|
| **Material** | Same woven tape as outer label |
| **Size** | 18 × 12mm |
| **Type** | Size only, in Söhne Mono |

### Placement
Adjacent to the inner composition label, sewn into the same seam, at the lower edge of the inner label.

### Why a separate flag
A separate flag allows the customer to remove only the size flag (e.g., for a gift) without losing the composition information. It is also easier to read at a glance from a hanger.

## 5. The repair sticker (post-purchase)

When a garment is returned to BESOQ for repair, it is sent back with a small additional label: a fabric sticker stitched onto the inside of the inner composition label, indicating the repair.

### Specifications
| Spec | Value |
|---|---|
| **Material** | Soft cotton tape, bone |
| **Size** | 20 × 8mm |
| **Print** | A single line in ash ink, 6pt: `repaired · 03.2027` |
| **Placement** | Stitched immediately below the existing inner label |

This is a **trace of life**, not a stain. It is the brand's quiet record of a garment kept long enough to need repair.

---

## 6. Forbidden label behaviours

- ❌ Labels with images (logos, illustrations, mascots).
- ❌ Glow-in-the-dark, reflective, or holographic labels.
- ❌ Labels that contain marketing copy ("luxury since 2026," "premium quality").
- ❌ Multiple country flags (e.g., a small flag for "made in Portugal").
- ❌ Labels longer than the inner composition label specified above.
- ❌ Stitching the brand name across the chest as a "label."
- ❌ Bonded / heat-pressed labels — they degrade faster than the garment.

---

## 7. Production notes

- All labels are sourced from a single weaver / printer per category, kept consistent across collections.
- Label production runs are scheduled with garment production, not separately, to avoid "vintage label / new garment" mismatches.
- A change to any label — even a minor one — requires updating `brand/CHANGELOG.md` and bumping the brand system version. Labels are part of the brand's permanent canon.
