# Stationery

The full set of paper goods used by the studio — internal, partner-facing, and customer-facing. Stationery is treated as an extension of the packaging: same paper philosophy, same restraint.

---

## The set

| Item | Use |
|---|---|
| Letterhead | Formal correspondence — partners, press, legal. |
| Compliments slip | Notes accompanying parcels (rare; mostly for press kits). |
| Business card | Team members. |
| Envelope C5 | Letterhead correspondence. |
| Envelope DL | Compliments slips, invoices. |
| Postcard A6 | Editorial mailings, archive correspondence. |
| Press kit folder | Press lookbook + image USB carrier. |
| Internal notebook | Atelier sketchbook for pattern work. |

## 3. Business card (85 × 55mm)

### Specifications
| Spec | Value |
|---|---|
| Paper | GF Smith Colorplan — Bone, 540 gsm (duplex if available) |
| Print method | Letterpress, both sides |
| Edge | Natural. No painted edge. |
| Corners | Square. No round corners. |

### Front

```
┌──────────────────────────────────┐
│                                  │
│                                  │
│                                  │
│              besoq               │   ← centred, 22mm wide
│                                  │
│                                  │
│                                  │
└──────────────────────────────────┘
```

### Back

```
┌──────────────────────────────────┐
│                                  │
│   [name]                         │   ← top-left, 9pt
│   [role]                         │   ← top-left, 9pt, charcoal
│                                  │
│                                  │
│                                  │
│   [email]                        │   ← bottom-left, 8pt
│   +[phone]                       │   ← bottom-left, 8pt
│                                  │
│                  be so quiet.    │   ← bottom-right, 7pt, stone
│                                  │
└──────────────────────────────────┘
```

### Forbidden behaviours
- ❌ Glossy or laminated finish.
- ❌ Foil printing on business cards.
- ❌ Edge gilding.
- ❌ QR codes on either side.
- ❌ Social handles (we do not advertise our handles on business cards — they are `@besoq` everywhere; the customer can find them).
- ❌ Job title gymnastics ("Chief Vibe Officer," "Wardrobe Curator"). Use plain titles.

## 4. Envelopes

### C5 envelope (162 × 229mm)
- Paper: Arena Natural, 120 gsm.
- Sealing: gummed flap. No self-seal.
- Print — back flap: wordmark `besoq` letterpressed, 18mm wide, centred 12mm above the seal line.
- No print on the front. The address is handwritten or laser-printed on a small bone label affixed to the front.

### DL envelope (110 × 220mm)
- Paper: Arena Natural, 100 gsm.
- Same construction as C5, scaled.

### Forbidden envelopes
- ❌ Window envelopes.
- ❌ Padded mailers (use the kraft mailer in `01-packaging.md` instead).
- ❌ Coloured paper.

## 5. Postcard A6 (105 × 148mm)

Used for editorial mailings to long-term customers, archive correspondence, and the rare seasonal announcement.

### Specifications
| Spec | Value |
|---|---|
| Paper | GF Smith Colorplan — Bone, 350 gsm |
| Print | Single-colour letterpress, ash on bone |

### Front
- A single editorial line, set in Times Now Light at 22pt, optically centred.
- Examples:
  - `the long coat. autumn 26.`
  - `the archive is open.`
  - `we will repair this.`

### Back
- Standard postcard divider line.
- Left half: handwritten message space.
- Right half: address space.
- Bottom-right: wordmark `besoq` at 12mm wide, ash.

## 6. Press kit folder (A4 + 2mm spine)

### Specifications
| Spec | Value |
|---|---|
| Material | Bone-toned uncoated card, 350 gsm |
| Construction | Single fold, no glue, no pocket |
| Print | Wordmark debossed, top-left, 32mm wide |

### Inner contents (no marketing inserts):
1. A4 letterhead with the press introduction (typed).
2. A6 card listing the season's garments by name.
3. USB-C drive (engraved with `besoq`) containing image files.
4. A single line printed on the inner-back: `press@besoq.com`.

### Forbidden
- ❌ Glossy folders.
- ❌ Folders with die-cut "BESOQ" letters on the front.
- ❌ Folders with photographs printed on the cover.

## 7. Internal notebook (atelier sketchbook)

The studio's working notebook. Used for pattern marking, fitting notes, and material samples.

### Specifications
| Spec | Value |
|---|---|
| Size | A5 (148 × 210mm) |
| Paper | Munken Pure, 100 gsm, plain (no rule, no grid) |
| Cover | Bone Colorplan with debossed wordmark |
| Binding | Section-sewn, exposed thread |
| Pages | 96 |

The notebook is internal but designed with the same care as customer-facing material — because it shapes the work that becomes customer-facing.

---

## 8. Forbidden stationery

- ❌ Branded mugs, pens, USB drives, lanyards, t-shirts, hoodies.
- ❌ Printed PowerPoint templates with photographic backgrounds.
- ❌ Plastic ID badges.
- ❌ "Sticker packs" or "BESOQ swag."
- ❌ Holiday cards with festive imagery.
- ❌ "Out of office" signs with personality.

The brand has no merchandise. There are no mugs. There are no tote bags with the wordmark printed loud (the cotton drawstring bag in `01-packaging.md` is the only branded textile, and it is a packaging item, not merchandise).
