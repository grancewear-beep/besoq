# Print kataloqu

Məhsulların üzərində nə olur. Qaydalar, ölçülər, nümunələr.

## Əsas prinsip

Print kiçikdir. Heç vaxt qışqırmır. Geyimin ən sakit hissəsidir — amma orada olduğunu bilirsən.

## Print tipləri

BESOQ üç növ print istifadə edir:

### 1. Wordmark print

Sadəcə `besoq` sözü. Kiçik. Sol döşdə, ya arxada boyun altında.

```
┌─────────────────┐
│                 │
│  besoq          │  ← sol döş, 3cm enində
│                 │
│                 │
│                 │
└─────────────────┘
```

### 2. Cümlə print

Qısa İngiliscə cümlə. Arxada, ortada, ya sol döşdə.

Mövcud cümlələr (əsas fond):

- `be so quiet.`
- `less is loud.`
- `say nothing.`
- `silence speaks.`
- `not here to shout.`

Hər drop-da 2–3 yeni cümlə əlavə oluna bilər. Amma yuxarıdakı beşi həmişə mövcuddur.

### 3. Qrafik element + söz

Kiçik həndəsi forma (dairə, xətt, nöqtə) + wordmark və ya cümlə. Şəkil yox, illüstrasiya yox.

Nümunələr:

```
┌─────────────────┐
│                 │
│  ○  besoq       │  ← kiçik dairə + wordmark, sol döş
│                 │
│                 │
└─────────────────┘
```

```
┌─────────────────┐
│                 │
│  ─── be so quiet. ───  │  ← iki xətt arasında cümlə, arxa orta
│                 │
└─────────────────┘
```

```
┌─────────────────┐
│         ·       │  ← kiçik nöqtə, arxada ortada yuxarıda
│                 │
│   be so quiet.  │  ← cümlə, arxada ortada
│                 │
└─────────────────┘
```

## Ölçü qaydaları

| Yer | Maksimum eni | Maksimum hündürlüyü |
|---|---|---|
| Sol döş | 5cm | 2cm |
| Arxa — yuxarı (boyun altı) | 12cm | 3cm |
| Arxa — orta | 20cm | 8cm |
| Qol | yoxdur (qolda print yox) |
| Ön tam | yoxdur (bütün ön üzü tutan print yox) |

## Rəng qaydası

Print rəngi sadədir:

| Geyim rəngi | Print rəngi |
|---|---|
| Ağ, açıq rəng | Qara (#1A1A1A) |
| Qara, tünd rəng | Ağ (#F4EFE6) |
| Boz (orta) | Qara və ya ağ (hansı daha kontrastlıdır) |

Heç vaxt rəngli print (qırmızı, yaşıl, mavi) istifadə olunmur. Yalnız monocrom.

## Texnologiya seçimi

Print texnologiyası print-in ölçüsünə görə seçilir:

| Print tipi | Texnologiya | Niyə |
|---|---|---|
| Kiçik wordmark (< 5cm) | Nakış (embroidery) | Premium hiss, 3D effekt |
| Orta cümlə (5–15cm) | DTF transfer | Dəqiq, incə detallar |
| Böyük arxa print (15cm+) | DTF və ya DTG | Geniş sahə, sürətli |
| Xüsusi effekt (reflective, puff) | Vinyl heat press | Nadir hallar üçün |

Əsas üstünlüyümüz — bütün texnologiyalar əlimizdədir. Hər drop-da fərqli texnologiya sınaya bilərik.

## Drop-lara xas print

Hər drop-un öz print fəlsəfəsi ola bilər:

**Drop 01 (nümunə):**
- Daimi xəttdə: wordmark embroidery
- Drop-specific: "be so quiet." DTF, arxada
- Xüsusi: bir model — reflective vinyl, yalnız 50 ədəd

**Drop 02 (nümunə):**
- Daimi xəttdə: wordmark embroidery
- Drop-specific: "say nothing." DTF, sol döşdə böyük
- Xüsusi: bir model — puff print, 3D effekt

## Nə etmirik

- ❌ All-over print (bütün səthi tutan naxış)
- ❌ Foto print (şəkil, mənzərə, portret)
- ❌ İllüstrasiya (çəkilmiş şəkil, cartoon)
- ❌ Rəngli print (qırmızı, yaşıl, mavi — yalnız monochrome)
- ❌ Qolda print
- ❌ Şalvarın ön hissəsində print (yalnız yan tərəfdə kiçik wordmark, opsional)
- ❌ Başqa brendin loqosu ilə collab print (gələcəkdə ola bilər, amma qaydası ayrıdır)
- ❌ Hər məhsulda başqa dizayn — bir drop daxilində bütün printlər bir ailədir

## Yeni cümlə əlavə etmə qaydası

Yeni drop üçün yeni cümlə icad etmək istəyirsən. Yoxla:

1. İngiliscə yazılıb? — bəli olmalıdır
2. 4 sözdən çox deyil? — ideal budur, max 6 söz
3. Nida işarəsi yox? — olmamalıdır
4. Hype söz yox? (amazing, incredible, fire) — olmamalıdır
5. Brendin "sakit" xarakterinə uyğundur? — bəli olmalıdır
6. T-shirt-in üzərində gözəl görünür? — sınayla

Əgər hamısı keçdi — əlavə et.
