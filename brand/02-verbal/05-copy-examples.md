# Copy examples library

A reference set of fully-drafted copy across the most common brand surfaces. Use these as starting templates — not to copy verbatim, but to calibrate voice when writing fresh copy.

---

## 1. Website — homepage

### Hero block
```
autumn 26.
on site now.
```

### Below hero — supporting line
```
twelve garments. one cloth. one cut at a time.
```

### About block (homepage)
```
besoq is a wardrobe brand built on restraint.
the name stands for be so quiet.
two collections a year, made slowly, kept long.
```

### Footer
```
besoq — care, repair, archive.
                                                          — besoq
```

## 11. Customer care — common scenarios

### "Can I get a discount?"
```
we do not discount our seasonal or permanent line.
when a season ends, the remaining stock moves to the archive at the original price,
and stays there until it is gone.

— sevda, besoq care
```

### "My garment has a defect."
```
we are sorry. send a photograph and your order number to repair@besoq.com.
we will replace the garment or repair it, whichever you prefer.
shipping is on us, both ways.

— sevda, besoq care
```

### "When is the next collection?"
```
spring 27 will release in early march.
the date is not announced until the cloth is in.

— besoq
```

### "Will [garment] come back?"
```
the boxy shirt is part of the permanent line and is restocked twice a year.
the long coat is seasonal and may not return in the same cloth.
if you would like to be told either way, leave your email here:
[link]

— sevda, besoq care
```
